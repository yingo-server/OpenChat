# OpenChat 用户指南

面向 OpenChat 的日常使用者。

## 账号

**注册与登录**（任选其一）：

- **手机号**：输入手机号 → 收到 6 位验证码 → 输入即完成（新号码自动注册）
- **邮箱**：输入邮箱 → 收到登录链接 → 点击即登录
- **微信 / Apple / 运营商一键登录**：按页面引导授权
- **游客模式**：无需注册先体验；之后绑定手机号或邮箱即升级为正式账号，聊天记录保留

**多设备**：同一账号最多 3 台设备同时在线。设置 → 设备管理 可查看并踢出任意设备。新设备登录时，所有已登录设备会收到通知。

**安全建议**：开启设置中的登录通知；发现陌生设备立即踢出并修改密码。

## 消息

- **发送**：文本、图片、语音（按住说话）、文件；单条文本上限 4000 字
- **撤回**：发送后 2 分钟内可撤回
- **回执**：单发显示送达 ✓ / 已读 ✓✓；群聊显示已读人数
- **离线**：断网时消息自动暂存本地，恢复后自动发出并补收离线消息

## 隐私与数据

- **屏蔽**：会话设置 → 屏蔽该用户
- **举报**：长按消息 → 举报（涉人身安全的举报优先处理）
- **数据导出**：设置 → 隐私 → 导出我的数据（资料、消息、媒体清单，30 天一次）
- **注销**：设置 → 账号 → 注销。15 天冷静期内可撤销；到期后 30 天内完成删除，聊天记录匿名化保留至法定期限

## 常见问题

**收不到验证码？** 同一号码每分钟限 1 条、每天限 10 条；当天第 2 条起需要先通过图形验证。仍然收不到请联系管理员。

**消息发不出去？** 检查顶部网络状态条。发送失败的消息带红色标记，点击即可重试。

**换了新手机，聊天记录还在吗？** 在。登录同一账号后自动同步；本地缓存的历史消息也可离线查看。

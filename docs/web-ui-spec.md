## 1. 设计原则与调性

### 1.1 视觉风格定位

**现代简洁类 IM**（参照微信/iMessage/Telegram 的交集）：信息密度优先、克制的装饰、圆角柔和、层级靠灰阶与间距区分而非边框堆叠。

| 原则 | 说明 | 反模式 |
|---|---|---|
| 内容即界面 | 聊天内容占 ≥70% 视觉面积，Chrome（导航/工具栏）低对比 | 大面积品牌色铺底、装饰性渐变 |
| 就近反馈 | 操作反馈出现在操作点附近（气泡红点、按钮 loading），而非全局弹窗 | 发送消息弹 toast |
| 静默状态可见 | 离线/重连/同步用顶部细条，不弹窗打断 | 断网时弹模态框 |
| 双端同构 | 移动/桌面同一组件，仅布局容器变化 | 为移动单写一套组件 |
| 高速感 | 动效 ≤300ms、骨架屏先行、点击 100ms 内必须有视觉响应 | 重 Web 动画、入场粒子 |

### 1.2 主题策略

- 实现：CSS variables（`:root` 亮色 / `[data-theme="dark"]` 暗色）+ Tailwind `darkMode: ['class']`，色值一律引用 `rgb(var(--token) / <alpha-value>)` 形式，禁止硬编码 hex。
- **切换不闪白**：
  1. 主题持久化于 localStorage，同时写入 `<html class="dark">` 由 Vite 注入的**内联阻塞脚本**在首次绘制前执行（index.html 内联，早于 CSS 加载）；
  2. `color-scheme: light dark` 同步设置，保证原生滚动条/输入控件跟随；
  3. 切换时给 `<html>` 加 `.theme-transitioning`（`transition: background-color 200ms`，仅限根/大面），300ms 后移除；
  4. 图片/头像不做反色，仅调背景面。
- 默认策略：跟随系统（`prefers-color-scheme`），用户手动选择后锁定并覆盖系统。

### 1.3 品牌色板（全状态色阶）

主色：**品牌蓝靛 #3B5BFD（亮色）**，暗色下提亮至 #5C7CFF。语义色各 6 阶（50/100/300/500 主/700 hover/900）。

| 语义 | 主色 500 | hover 600 | active 700 | disabled | 亮色文本 | 暗色 500 |
|---|---|---|---|---|---|---|
| primary | #3B5BFD | #2F4CE8 | #2540C9 | #A8B5F5(bg)/text 40% | #FFF | #5C7CFF |
| success | #16A34A | #12803C | #0E6630 | #9CCDB0 | #FFF | #22C55E |
| warning | #F59E0B | #D9860A | #B26F08 | #F3D9A2 | #1F2937(深字) | #FBBF24 |
| danger | #E5484D | #C9383D | #A82E33 | #EFB0B2 | #FFF | #F2555A |
| info | #0EA5E9 | #0284C7 | #0369A1 | #A3D8F5 | #FFF | #38BDF8 |

规则：
- 主色仅用于"我的消息气泡、主按钮、选中态、未读角标"；不得用于正文链接以外的大面积装饰。
- danger 用于：发送失败红点、撤回确认、举报、封禁页；不得与"删除"以外的高频操作混用。
- disabled：背景用主色 50/100 阶，文字 40% 不透明度，cursor: not-allowed，仍可聚焦（供读屏说明）。

### 1.4 字体系统

```css
font-family:
  -apple-system, "PingFang SC", "HarmonyOS Sans SC", "MiSans",
  "Noto Sans SC", "Microsoft YaHei", system-ui, sans-serif;
/* 数字等宽（时间戳/未读数/进度） */
--font-mono-nums: "SF Mono", ui-monospace, "Cascadia Mono", Consolas,
  "Noto Sans SC", monospace;
```

| 层级 | token | 亮色尺寸/行高 | 用途 |
|---|---|---|---|
| display | text-display | 24/32 (bold) | 空状态标题、封禁页标题 |
| title | text-title | 17/24 (600) | 会话名、聊天窗标题 |
| body | text-body | 15/22 | 消息正文、列表摘要 |
| body-sm | text-body-sm | 13/20 | 时间戳、次要信息 |
| caption | text-caption | 12/16 | 角标、占位符、表单辅助文字 |
| 表格/后台 | text-table | 14/20 | 管理后台正文 |

- 中文优先：禁用 `line-break` 类 hack，`word-break: break-word` 用于气泡；中英文混排自动加 1/8 em 间距（`text-autospace` 可用则开启）。
- **等宽应用**：所有时间戳、未读数、文件大小、进度百分比、验证码倒计时统一加 `font-feature-settings: "tnum"` + 等宽栈 class `nums`，避免数字跳动。
- 字号缩放：根字号不缩放（布局是 px），但正文/气泡/列表文字用 rem，随用户设置 `html { font-size: 100%/112.5%/125% }` 三档缩放（详见 §7.3）。

### 1.5 圆角 / 阴影 / 间距

- **间距：4px 基准网格**。所有 margin/padding/gap 取 `4 × n`（4/8/12/16/24/32/48/64），禁止 5/10/18px 等非基准值。
- 圆角阶梯：`sm 6px`（输入框/标签）、`md 10px`（按钮/卡片）、`lg 14px`（气泡外侧角）、`xl 20px`（模态框/抽屉）、`full 999px`（头像/角标）。气泡采用**方向性圆角**：自己的气泡右下角 4px、其余 14px；对方相反。
- 阴影三档 + 暗色规则：

| token | 亮色 | 暗色策略 |
|---|---|---|
| shadow-sm | `0 1px 2px rgb(0 0 0 / .05)` | 亮度差替代阴影 |
| shadow-md | `0 4px 12px rgb(0 0 0 / .10)` | `0 4px 12px rgb(0 0 0 / .50)` |
| shadow-lg | `0 12px 32px rgb(0 0 0 / .14)` | `0 12px 32px rgb(0 0 0 / .60)` |

- 暗色下" elevation = 表面色变亮"：浮层背景 `surface-elevated`（比 surface 亮一阶）+ shadow-md。
- 图标：统一 24×24 网格描线图标（stroke 1.5px，`currentColor`），尺寸档 16/20/24。
- 分割线：1px，亮色 `#E5E7EB`，暗色 `#2A2D34`，优先用间距替代分割线。

## 2. 布局系统

### 2.1 三栏结构与断点行为

```
桌面 ≥1200px
┌────────┬──────────────────────┬─────────────┐
│ 会话列表 │       聊天窗          │  详情侧栏    │
│ 280px  │   flex-1 (min 480)   │  320px      │
│ 固定    │                      │ 可折叠       │
└────────┴──────────────────────┴─────────────┘

平板 768–1199px          移动 <768px
┌────────┬───────────┐   ┌─────────────┐
│会话列表 │  聊天窗    │   │  单栏路由导航  │
│ 88px   │           │   │ 列表⇄聊天⇄详情│
│收窄 or  │ 详情→抽屉  │   │ 左右滑切换    │
│抽屉     │           │   └─────────────┘
└────────┴───────────┘
```

| 断点 | 宽度 | 布局 | 详情侧栏 | 会话列表 |
|---|---|---|---|---|
| desktop | ≥1200 | 三栏并列 | 固定侧栏，可折叠为 0 | 固定 280px |
| tablet | 768–1199 | 两栏 | 覆盖式抽屉（右侧滑出，遮罩点击关闭） | 固定收窄为 88px（仅头像+角标），或列表/聊天二选一路由 |
| mobile | <768 | 单栏 | 全屏路由页（带返回键） | 全屏路由页，进入会话后列表卸载（虚拟列表销毁）而非隐藏 |

- 平板策略二选一由产品配置；本规范默认 **收窄侧栏 + 详情抽屉**。
- 移动端三页（列表/聊天/详情）用栈式路由；返回手势（边缘右滑）必须支持。

### 2.2 安全区与视口

- `<meta name="viewport" content="width=device-width, viewport-fit=cover, maximum-scale=1">`（maximum-scale=1 为防 iOS 输入聚焦缩放，需配合 16px 输入字号，见 §7.3 替代方案）。
- 所有贴边容器（底栏、输入栏、下拉菜单）加 `env(safe-area-inset-bottom/top/left/right)` padding；`.msg-input { padding-bottom: max(12px, env(safe-area-inset-bottom)) }`。
- 输入栏吸底：`position: sticky; bottom: 0`，键盘弹起时用 `visualViewport` API 调整（`interactive-widget=resizes-content`），输入栏始终可见。
- 100dvh 代替 100vh（移动端地址栏），应用根容器 `height: 100dvh; overflow: hidden`，内部各栏独立滚动。

### 2.3 虚拟滚动容器约束

- 消息区、会话列表均用虚拟滚动（回收 DOM）。约束：
  - 滚动容器必须是**唯一的 overflow 元素**，高度确定（flex 布局中 `min-height: 0` 必须显式声明）；
  - 容器内禁止依赖原生 scrollbar 定位；跳转锚点由虚拟列表的 scrollToIndex 实现；
  - 子项高度可变：气泡用预估高度 + 渲染后测量校正，校正不得引起 >2px 视觉跳动；
  - 桌面滚动条：overlay 式细滚动条（8px，半透明），移动端隐藏原生滚动条；
  - 虚拟列表 padding 上下各 16px，底部预留"跳到底部"按钮空间。

## 3. 组件规范

> 通用规则：所有组件 props 中与文案相关的必须传 i18n key 渲染结果；所有交互组件有 `:focus-visible` 样式（2px 主色 outline，offset 2px）。

### 3.1 按钮 Button

| 变体 | 亮色样式 | 用途 |
|---|---|---|
| primary | 品牌蓝底 + 白字 | 每屏至多 1 个（发送、登录主操作） |
| secondary | 白底 + 1px 边框 `border-gray-200` + 深字 | 次要操作（取消） |
| ghost | 透明底 + 主色字，hover 灰底 | 工具栏图标按钮 |
| danger | danger 底 + 白字 | 撤回确认、举报提交、退出群聊 |

| 尺寸 | 高度 | 内边距 | 字号 | 图标 |
|---|---|---|---|---|
| sm | 28px | 8px | 13 | 16 |
| md | 36px | 16px | 15 | 20 |
| lg | 44px | 24px | 17 | 20 |

- **loading 态**：左侧出现 16px 旋转 spinner，按钮文字保留、宽度锁定不抖动，禁点，200ms 内完成的请求**不显示** loading（防闪烁，§5.3）。
- disabled 态见 §1.3；danger 变体 disabled 用 100 阶底 + 深字。
- 点击热区：移动端最小 44×44px（ghost 图标按钮用 padding 扩展热区）。

### 3.2 输入框 Input / Textarea

- 高度 md 36px；边框 1px `gray-300`，focus 时主色 2px（box-shadow 实现，避免布局跳动）；错误态 danger 边框 + 图标 + 下方 12px 错误文案。
- 多行输入（消息输入框）：最大高度 40vh（约 8 行），超出内滚动；Enter 发送 / Shift+Enter 换行（桌面），移动端 Enter 换行、发送靠按钮。
- **字数统计**：达到上限 90% 时出现在右下角 `nums` 等宽 `123/500`；超限时计数变 danger 并阻止输入（textarea maxlength）。
- 附带功能槽：左侧图标位、右侧清除按钮（仅桌面，出现条件：非空 + 聚焦）。

```
┌──────────────────────────────────────┐
│ ⊕ 请输入消息…                😊 📎 ➤ │   ← 桌面输入栏
└──────────────────────────────────────┘
```

### 3.3 消息气泡 MessageBubble

| 类型 | 背景（亮/暗） | 尾部/角标 |
|---|---|---|
| 自己 | 主色 / #5C7CFF | 无尾;失败时右侧 12px danger 圆点 |
| 对方 | #F3F4F6 / #26282E | 头像在左侧(列表首条带头像,连续消息省略) |
| 系统消息 | 无气泡，居中 caption 灰字 | — |
| 引用回复 | 气泡顶部 2px 主色竖线 + 缩略引用块（点击跳原消息） |
| 撤回占位 | 无气泡样式，居中灰字："你撤回了一条消息"，原文是自己可加"重新编辑"链接（2 分钟内） |

```
对方                        │ 自己
┌──────────────┐            │        ┌──────────────┐
│ (引用预览一行…)│            │        │ 收到了 ✅     │
│ 你好，在吗？   │            │        └──────────────┘
└──────────────┘            │ 14:02 ●   ↑12px红点=发送失败,点击重试
              14:01         │        ┌──────────────┐
                            │        │ [发送中⏳=转圈]│
                            │        └──────────────┘
```

- 气泡最大宽度：桌面 60% 容器宽（≤560px），移动 78%。
- 状态机：`sending（灰色 60% 透明+spinner）→ sent（单勾）→ delivered（双勾）→ failed（红点 + hover/点击出重试菜单）`；已读回执由产品开关控制，默认单聊展示。
- 长按（移动）/右键（桌面）/hover 出现操作菜单（§3.7）。多选模式见 §4.6。

### 3.4 会话列表项 ConversationItem

```
桌面 64px 高                              移动 72px
┌────┬─────────────────────────┬──────┐
│头像 │ 张三          🔕 📌     │ 14:02│
│ 48 │ 你: 好的，明天见 [图片]  │  ③   │   ← 未读角标
└────┴─────────────────────────┴──────┘
草稿: 未发送内容红色显示 "草稿: xxx"
```

- 组成：头像 48px（移动 52px）+ 名称（1 行截断）+ 摘要（1 行截断，媒体消息用类型图标替代文案：`[图片] [语音] [文件名]`）+ 时间（今天显示 HH:mm，昨天显示"昨天"，更早显示 MM-DD）+ 右上未读角标（≥99 显示 `99+`，红色 danger，`nums` 等宽）。
- 角标变体：`@我` 提及角标为品牌红 + 文字"@"; 静音时角标灰底；置顶项背景加灰底色区分；选中项主色 50 阶底。
- 图标：置顶 📌（右上角小图）、静音 🔕（名称右侧 12px 灰）。
- 交互：hover（桌面）出删除/置顶/已读快捷按钮；移动端左滑出操作（§5.4）。

### 3.5 头像 Avatar

| 尺寸 | 直径 | 用途 |
|---|---|---|
| xs 24 | 聊天窗标题返回处、消息操作者 |
| sm 32 | 群成员列表、@提及候选 |
| md 48 | 会话列表、消息 |
| lg 64 | 聊天窗标题、个人资料卡 |
| xl 96 | 自己的资料页 |

- **群头像九宫格**：≤9 成员取前 9（按活跃度）3×3 切分原头像缩略图；1 人直接用该头像；纯色底 + 首字符为 fallback。加载失败显示首字符 + 按用户 ID hash 的色板底色。
- **presence 圆点**：右下角，直径 10px（md）/8px（sm）；在线 success 实心、离开 warning、离线灰边透明心；仅出现在有 presence 数据的场景。加 `title`/aria-label "在线"。

### 3.6 Toast / Snackbar

- 位置：移动端底部（安全区上方 16px）居中；桌面右上角（不覆盖聊天输入区）。
- 单例队列，最多同时 1 条，自动消失 3s（含操作按钮时 5s），消失动画 200ms fade+translateY(8px)。
- 类型：info（默认，深灰底白字）、success（前缀 ✓ 图标）、danger（⚠）。**toast 不承载错误详情**，详情错误一律表单内联或模态框。
- 可带一个文字操作（如"重试"），文字用主色。

### 3.7 模态框 / 抽屉 / 菜单

- **模态框**：宽 400px（sm）/ 560px（md），圆角 xl，遮罩黑 40%（暗色 60%），禁止背景滚动；进出 200ms（scale .96→1 + fade）。**对话类模态框（确认撤回/举报）在移动端改为底部动作面板（bottom sheet）**。
- **抽屉**：右侧滑入（详情/设置），宽度 320px（桌面覆盖）、100%（移动）；`overscroll-behavior: contain`。
- **下拉/右键菜单**：统一的 `Menu` 组件，桌面右键、移动长按（450ms）触发。
  - 消息操作菜单（按角色动态裁剪）：
    - 通用：回复、复制（仅文本）、转发、多选、举报
    - 自己的消息（2 分钟内）：撤回（→确认 bottom sheet："撤回后对方将看到撤回提示"）
    - 群管理员：删除（对他人）
  - 菜单项：40px 高，图标+文字，danger 项（撤回确认后的执行/举报）红字；触发菜单时原消息高亮（主色 50 阶底）。
  - 出现位置自动翻转（flip）避免出屏；菜单打开时 Escape/点击外部关闭。

### 3.8 骨架屏 / 空状态

- **骨架屏**：形状与真实内容一一对应（头像圆 + 两行条），动画为 1.2s 循环的亮度波（`background-size` 位移实现，不用 transform 循环大区域）。应用于：会话列表首次加载、聊天窗历史加载、资料卡。**局部刷新不用骨架屏**（保留旧内容 + 顶部同步指示）。
- **空状态**：预留 160×160 插画位（SVG，双主题两套或 `currentColor` 单套），下方主文案 + 次文案 + 可选主按钮。

| 场景 | 主文案 | 次文案 | 按钮 |
|---|---|---|---|
| 会话列表空 | 还没有会话 | 从通讯录或搜索开始聊天吧 | "发起聊天" |
| 搜索无结果 | 未找到相关结果 | 换个关键词试试 | — |
| 管理后台空表 | 暂无数据 | — | — |

## 4. 消息区专项规范

### 4.1 分隔线体系

| 分隔线 | 触发条件 | 样式 |
|---|---|---|
| 日期分割线 | 跨自然日 | 居中胶囊灰底白字"3月15日"/"昨天"/"星期二" |
| 时间分组线 | 与上条消息间隔 >5 分钟 | 对方消息头像上方加 8px 空隙 + 头像重新出现（不画线，用间距+头像回归表达） |
| 新消息分隔线 | 停留后收到新消息（且不贴底） | 居中主色细字"↓ 新消息"按钮式分隔条，点击跳到最新 |
| 未读分隔线 | 进入会话时从上次阅读位置开始有未读 | 居中细线 + 主色文字"以下未读"（unread marker 是虚拟列表锚点，`scrollToIndex` 停在其后一条） |
| 撤回/系统 | — | 居中 12px 灰字（见 §3.3） |

### 4.2 图片消息

加载三级：**blurhash 占位（16px 高斯模糊基底，宽高比容器）→ 缩略图（~360px 边）→ 点击查看器加载原图**。

- 尺寸规则：按原图宽高比，宽 = `min(容器宽 60%, 原图宽)`，**按 3 档宽度收敛**（小图 160 / 中 240 / 大 320px，避免每张宽度不同造成虚拟滚动测量抖动）；容器必须有确定的 aspect-ratio 以防 CLS。
- 圆角 lg；gif 标"动图"角标；多图（相册消息）按九宫格排布，>4 用" +N"遮罩。
- 查看器：全屏遮罩，双指/滚轮缩放、左右切换、长图支持；信息栏含发送者与时间。

### 4.3 语音消息

```
对方                                  自己
┌──────────────────────────┐        ┌──────────────────────────┐
│ ▶ ▁▂▃▅▂▁▃▂▅▁▂▃▂▁ 12"     │        │ ▁▃▅▂▁▃▂▅▁▂▃▁▂▃ 8"  ●未读  │
└──────────────────────────┘        └──────────────────────────┘
   ↑波形24段,高度按采样生成,宽度与时长成正比(60s封顶比例)
```

- 波形固定 **24 段**，段高 3–20px 随机感由音频能量生成（无能量数据时用时长 hash 伪随机，保证同条消息渲染一致）。
- 播放：点击后当前会话仅一条在播（新播放停止旧的）；**播放进度高亮**：已播段变主色，未播灰；播放头段做 1.5 倍高度呼吸动画（100ms 律动）。
- 未读红点：右侧 8px danger 圆点，首次播放后消失（并回写已读）。
- 2 秒内语音直接显示时长不显示波形（按"小"尺寸气泡）。

### 4.4 文件消息

```
┌────────────────────────────────┐
│ ┌────┐ 项目规划书.pdf           │
│ │ 📄 │ 2.4 MB · 点击下载        │
│ └────┘ [──────░░░░ 64% ─────]   │ ← 接收中的进度条(完成后消失)
└────────────────────────────────┘
```

- 类型图标按扩展名映射 5 类：文档📄/表格📊/演示📽/压缩📦/其他📎，图标底色按类型用语义色 100 阶。
- 文件名 1 行截断（中 truncation）；大小、进度用 `nums` 等宽；下载/发送进度条 4px 高全宽，主色填充。
- 视频消息（预留）：封面帧 + 居中播放按钮，样式同图片消息规范。

### 4.5 消息多选模式

- 入口：消息菜单"多选"。顶部工具栏替换为"已选 3 条 | 转发 | 合并转发 | 删除 | 取消"。
- 每条消息左侧出现 24px 复选框位；点击整条切换选中；选中项主色 50 阶底；菜单/长按禁用，返回键退出。

### 4.6 滚动锚定策略

| 场景 | 行为 |
|---|---|
| 打开会话（有未读） | 滚动至未读分隔线后一条，上方显示"↑ 查看更早消息 N 条"胶囊 |
| 打开会话（无未读） | 贴底（最后一条） |
| 贴底状态收到新消息 | 自动跟随贴底（带 200ms 进入动画，**节流**：连续消息时只在间隙 ≥300ms 时播放，否则直接追加） |
| 用户上滚离开底部 >120px | 停止跟随，显示"↓ 新消息 N"浮层按钮 |
| 上拉加载历史 | **保持视口位置不跳动**：加载后以"当前视口第一条可见消息"为锚，向 scrollToIndex 恢复偏移；加载中顶部显示 mini spinner |
| 图片加载完成尺寸变化 | 以用户当前阅读位置为锚补偿滚动，不得把用户视口顶走 |

## 5. 交互与动效规范

### 5.1 时长与缓动

| 档位 | 时长 | 用途 |
|---|---|---|
| micro | 100ms | hover 背景变化、按钮按下、复选框 |
| normal | 200ms | 菜单弹出、模态进出、toast、气泡进入 |
| slow | 300ms | 抽屉、页面级转场、主题切换过渡 |

缓动曲线：出场统一 `cubic-bezier(0.2, 0, 0, 1)`（标准），退场 `ease-in`；弹出类菜单用 origin 缩放（scale .96→1）。

### 5.2 动画实现约束

- **只允许 transform / opacity**（含由其合成的 filter）触发动画；禁止 animate width/height/top/margin。
- 波形播放、未读角标脉动等循环动画，在组件不可见（虚拟列表滚出）时暂停（IntersectionObserver）。

### 5.3 防闪烁规则

- 骨架屏 → 内容：**内容在骨架出现 <300ms 内到达时，不闪骨架**（延迟渲染骨架）；骨架最少展示 300ms（若内容中途到达，补足至 300ms 再替换），保证不会"闪一下"。
- loading 按钮、下拉刷新 spinner 同理遵守 300ms 最小展示。

### 5.4 下拉刷新 / 上拉加载 / 滑动手势

- 下拉刷新（仅移动端会话列表）：拖动 64px 触发，期间顶部 spinner 跟手位移，松手回弹 200ms。
- 上拉/上滚加载历史：距顶 200px 预加载；不得依赖 overscroll（iOS 橡皮筋不可用）。
- **移动端会话项左滑**：露出右侧操作按钮组（标为已读/置顶/删除，danger 颜色区分删除）；滑动为 transform 跟手，松手 100ms 吸附开/关；同时仅一条展开，点按他处收回。

### 5.5 Reduce Motion

- `@media (prefers-reduced-motion: reduce)`：所有 transition/animation 时长归 0；骨架屏改为静态灰块；呼吸/脉动动画删除；保留即时状态切换。以系统设置为准，不提供应用内覆盖（跟随系统偏好）。

## 6. 状态与反馈

### 6.1 网络状态提示条

- 位置：聊天窗顶部、会话列表顶部各一条 28px 细条，出现/消失用高度+opacity 过渡（200ms），**绝不弹窗打断输入**。

| 状态 | 文案 | 样式 |
|---|---|---|
| 离线 | 当前网络不可用，消息将在恢复后发送 | danger 50 阶底 + 图标 |
| 重连中 | 连接中… | warning 底 + mini spinner |
| 已恢复 | 已恢复连接（自动收起） | success 底，1.5s 后收起 |

### 6.2 消息发送状态

- sending：气泡 60% 透明 + 右下 spinner（§3.3）；用户可继续输入发送后续消息（本地乐观插入，按 localId 排序）。
- failed：右下 12px 红点；hover/点击弹菜单：重试 / 删除；断网期间批量 pending，恢复后按序重发。
- 排序规则：本地乐观消息排最后；服务端确认后按服务器时间重排（同秒内保持稳定，不闪跳）。

### 6.3 会话同步中

- 首次登录/换设备：会话列表骨架屏 + 顶部"正在同步消息…"；增量同步不打断，仅列表项时间/摘要原地更新。

### 6.4 封禁页 / 维护页

- 全屏路由替换（不可返回），居中插画位 + 标题 + 说明 + 客服入口。

```
封禁页：  标题"账号已被封禁"  说明"您的账号违反了社区规范（原因：xxx），
          如有疑问可联系客服申诉。" 按钮[联系客服]
维护页：  标题"系统维护中"  说明"预计 30 分钟内恢复，请稍后再来。"
          （无按钮，自动 60s 轮询恢复）
```

### 6.5 登录流程流转（文字流程图）

```
入口选择页（游客模式直接进入 · 手机验证码 · 邮箱魔法链接 · 密码 · 微信 · Apple · 一键登录）
├─ 游客模式 ────────────→ 进入应用（受限：无法发媒体/建群）→ 触发升级引导（§6.6）
├─ 手机验证码：输入手机号 → 获取验证码（60s 倒计时, nums）→ 输入 6 位 OTP（自动焦下一格/自动提交）→ 成功/错误内联提示
├─ 邮箱魔法链接：输入邮箱 → 提示"登录链接已发送至 xx@xx.com"（含"打开邮件应用"按钮）→ 回跳验证页轮询 → 成功
├─ 密码：账号+密码 → 失败 5 次出现图形验证码 → 成功
├─ 微信 / Apple：拉起 SDK/新窗 OAuth → 回调 → 补充资料页（可选：昵称头像，可跳过）
└─ 一键登录（运营商）：SDK 拉起 → 确认页[本机号码登录] → 成功
所有首次登录 → 引导页（通知/通讯录权限，均可跳过）→ 进入会话列表
```

- 每步失败均为**内联红字**于表单下方，不清空已输入内容；登录中按钮 loading 并防重复提交。

### 6.6 游客升级引导

- 时机（只在用户产生"价值依赖"时弹，**频控：每类 7 天最多 1 次**）：
  1. 尝试发送第 10 条消息（"游客数据换设备会丢失，注册后可保留"）；
  2. 尝试发送图片/文件（"注册后才能发送媒体消息"）；
  3. 建群/加好友时。
- 形式：优先**底部非模态横幅**（带"注册"按钮），仅第 2 类用 bottom sheet 说明并给快捷注册入口；**禁止**进入应用立即弹、禁止打断正在输入的用户（输入框聚焦时延后到失焦后）。
- 文案原则：说明"注册能获得什么"（数据保留/完整功能），而非限制恐吓；一键可完成注册的按钮永远可见。

## 7. 无障碍与国际化预留

### 7.1 键盘导航

| 区域 | 按键 | 行为 |
|---|---|---|
| 全局 | `Ctrl/Cmd + K` | 搜索 |
| 会话列表 | ↑/↓ | 移动选中会话，Enter 进入 |
| 消息列表 | ↑/↓（或 J/K） | 在消息间移动焦点（focus ring），焦点消息自动滚入视口 |
| 焦点消息 | Enter | 打开消息操作菜单 |
| 焦点消息 | R | 快捷回复 |

| 全局 | Esc | 逐层关闭：菜单 → 多选 → 抽屉 → 模态 |

- 消息使用 `role="log"` + `aria-live="polite"` 的容器（仅新消息追加时朗读摘要，且在用户主动滚动时静默）。

### 7.2 ARIA 最小集

| 组件 | role / 属性 |
|---|---|
| 会话列表 | `role="listbox"`，项为 `option`，`aria-selected` |
| 消息 | `role="listitem"`（列表容器 role="log"），aria-label="张三 14:02 发送的文本：xxx" |
| 未读角标 | 合并入列表项 aria-label："张三，3 条未读" |
| 头像 | `role="img"` + alt="张三的头像"；装饰性图标 `aria-hidden` |
| 菜单 | `role="menu"` / `menuitem`，触发按钮 `aria-haspopup` / `aria-expanded` |
| 模态 | `role="dialog"` + `aria-modal`，焦点圈定（focus trap） |
| toast | `role="status"` + `aria-live="polite"` |
| 输入框 | label 或 `aria-label`，错误 `aria-describedby` + `aria-invalid` |
| 网络提示条 | `role="status"` |

### 7.3 字号缩放

- 设置内三档：标准 / 大 / 特大 → `html` font-size 16/18/20px，文本用 rem 自动跟随；布局（栏宽、头像、图标）保持 px 不缩放。
- 输入框字号 ≥16px（移动端），防 iOS 聚焦自动放大。

### 7.4 国际化预留

- 全部文案走 i18n key，**目录规范**：`src/locales/zh-CN/*.json`（基准语言，按域拆分：`common/auth/chat/report/admin`），新增语言平行目录 `en-US` 等；zh-CN 缺 key 即构建报错（CI 校验 key 完整性）。
- 禁止：字符串拼接文案（用插值 `{name}`）、在组件内写死中文、依赖中文长度假设的截断（用 CSS ellipsis）。
- **RTL 预留**：所有左右语义类用 Tailwind 逻辑属性写法（`ms-*`/`me-*`/`ps-*`/`pe-*`/`start-*`/`end-*`，禁用 `ml/mr/pl/pr/left/right`）；气泡方向、头像位置、滑动手势方向由 CSS 变量 `--dir` 驱动的逻辑布局自动翻转；时间戳/未读数等数字方向保持 LTR（`dir="ltr"` + isolation）。本期不交付 RTL 语言，但上述规则进入 Code Review 检查单。

## 8. 性能规范

### 8.1 指标目标

| 指标 | 目标 | 说明 |
|---|---|---|
| LCP | <2.5s（4G 中端机） | 首屏为会话列表骨架 + 列表首屏数据 |
| FCP | <1.0s | 内联关键 CSS，路由分包 |
| INP | <200ms | 消息发送点击到乐观渲染 |
| CLS | <0.1 | 图片 aspect-ratio、字体 swap fallback 字面匹配 |
| 长任务 | 无 >200ms | 列表分片渲染 |

### 8.2 组件级规范

- **消息列表不得整列表重渲染**：消息项组件 `React.memo`，props 仅传 `messageId` + store selector 订阅单条（Zustand per-item selector），列表容器订阅分页窗口与锚点状态。
- 气泡内部子组件（波形/状态角标/引用块）独立 memo；`Bubble` 结构与内容分离——状态变化（sending→sent）只重渲染状态角标子组件。
- 会话列表项同理按 conversationId 订阅，未读数变化不重渲染兄弟项。
- 任何 map 渲染必须稳定 key（服务器 id 或 localId，禁止 index）。

### 8.3 图片策略

- 懒加载 `loading="lazy"` + `decoding="async"`；缩略图尺寸与显示尺寸匹配（不传大图进列表）；查看器原图预加载前一张/后一张。
- blurhash 在主线程解码一次后缓存 offscreen canvas；并发解码 ≤4（队列）。
- 大图用 `content-visibility: auto` 配合虚拟列表。

### 8.4 动画 / 字体

- 动画只用 transform/opacity（§5.2），虚拟列表项出入不做逐项动画。
- **中文字体子集化**：UI 字体不内嵌全量中文；按需切片（常用 3500 字 + 界面文案字符集合并去重 → woff2 分片 + unicode-range 自动按需加载）；数字等宽栈优先系统字体避免额外下载。构建产出字体切片报告，总初始字体 <200KB。

## 9. 管理后台规范差异

- **共享设计令牌**（§10 同一份 tokens：颜色/字号/圆角/动效），布局独立：左侧固定侧边导航 240px（可收窄 64px 图标态）+ 顶栏 56px（面包屑 + 管理员身份 + 退出）+ 内容区 24px padding。

└────────┴─┴──────────────────────────────┴──┘

### 9.1 表格规范

- 行高 48px，斑马纹禁用（用 hover 底色），列头可排序（首次点击升序图标▲，再次降序▼）。
- 筛选条在表格上方：状态用下拉、时间用日期区间、搜索为防抖 300ms 的输入框；筛选生效即时请求（loading 时表格置灰不清空）。
- 分页：底部右对齐 `共 342 条 ‹ 1 2 3 … 9 › 每页 [20▾]`，数字用 `nums`。
- 批量：首列复选框，全选含跨页提示"已选本页 20 条 [选择全部 342 条]"；批量操作按钮（封禁/解封/导出）出现在底部操作条，danger 操作需模态确认并列出受影响数量。
- 行内状态标签：`●正常`(success)/`●已封禁`(danger)/`●待处理`(warning)/`●已处理`(灰)，8px 圆点 + 13px 文字。

### 9.2 审计日志查看器（journalctl 式顺序流）

- 单列顺序流 UI：时间（等宽、行首固定宽）+ 事件类型标签 + 操作者 + 摘要；**向上无限滚动追加更早日志**（同 §4.6 锚定），底部实时跟随新条目（有"暂停跟随"开关）。
- 顶部过滤：时间段 + 事件类型下拉 + 自由文本 grep（高亮命中）。
- 每行可展开查看完整 JSON 载荷（缩进树形视图）；点击时间戳复制 ISO 值。
- 性能：行虚拟滚动；行背景跟随类型微着色（danger 事件 50 阶底）。

### 9.3 其他差异

- 后台不使用 bubble/toast 高频动效；danger 操作（封禁/解封/广播发布）一律二次确认模态，广播发布需输入确认词。
- 后台文案同样走 i18n（`locales/zh-CN/admin.json`）。
